# 🚀 Mars Drift

**Mars Drift** is a 3D rocket-based arcade game set on the surface of Mars. The game revolves around controlling a rocket using simple left-and-right movement while using a powerful boost to navigate through the environment and reach the finish.

## 🎮 About the Game

In **Mars Drift**, you take control of a rocket exploring a Mars-inspired environment filled with obstacles and challenging paths. The rocket has limited directional control, making momentum and timing important when navigating through the levels.

The main objective is simple: **reach the finish without crashing.**

Although the controls are easy to understand, controlling the rocket effectively requires careful movement and good timing. The boost can be used to quickly change the rocket's movement and gain the speed needed to get through difficult sections.

As the player progresses, the level layouts introduce different obstacles and situations that require more precise control of the rocket.

## 🕹️ Controls

## 📚 Development

**Mars Drift** was developed as a solo game development project and served as a hands-on learning experience with Unity and C#.

While developing the game, I worked with several aspects of game development including:

* 3D player movement and physics
* Rocket boost mechanics
* Collision detection
* Particle effects and rocket thrusters
* Level and obstacle design
* Camera systems using Cinemachine
* Audio implementation
* Scene and level management

The project was built from scratch with the goal of learning more about the complete process of creating and releasing a playable game.
